 # User Data Deletion Instructions

Quran Reels Publisher does not store, retain, or process user personal data on external databases.

If you wish to remove your interactions or have concerns regarding data related to this application:

1. Go to your Facebook Profile's **Settings & Privacy** > **Settings**.
2. Navigate to **Apps and Websites**.
3. Locate **Quran Reels Publisher** (or your app name).
4. Click **Remove**.
5. To request deletion of any cached server logs, submit an issue on our GitHub repository or contact the administrator directly.
